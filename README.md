 # Computer Vision & Deep Learning Challenges

Proyecto académico enfocado en visión por computador e inteligencia artificial, desarrollando soluciones de aprendizaje profundo para clasificación y restauración de imágenes utilizando Python y arquitecturas avanzadas de Deep Learning.

## Tecnologías utilizadas

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Retos desarrollados

### Clasificación de escenas
Implementación de modelos de Deep Learning para clasificación de escenas como bosques, costas y autopistas, utilizando redes convolucionales y arquitecturas como ResNet.

### Clasificación de cobertura terrestre (LandUse)
Desarrollo de modelos para clasificación de imágenes satelitales de cobertura terrestre mediante técnicas de aprendizaje profundo y análisis comparativo con modelos tradicionales de Machine Learning.

### Autoencoder para reducción de ruido SAR
Implementación de autoencoders y arquitecturas tipo U-Net para filtrado de ruido speckle en imágenes SAR, evaluando resultados con métricas como SSIM, PSNR y ENL.

### Restauración de imágenes con Transformers
Aplicación de modelos basados en Transformers (SWINIR) para restauración y mejora visual de imágenes con ruido o degradación.

## Resultados

- Evaluación mediante métricas matemáticas y análisis visual.
- Comparación de rendimiento frente a modelos tradicionales de Machine Learning.
- Experimentación con arquitecturas avanzadas de Deep Learning y ajuste de hiperparámetros.
